# Final result files

The compact summary tables and statistical summaries for UCI, MORED V3 and London are stored in this folder and `Results_DAT_corrected_fullbes/`.

The complete final UCI corrected V2 and MORED corrected V3 prediction arrays, target arrays, timestamps, run configurations, per-seed result CSVs, integrity audit outputs and statistical analysis outputs are provided in:

` supplementary/FINAL_UCI_MORED_V3_PREDICTIONS_AND_AUDITS.zip `

This artifact intentionally excludes superseded MORED V2 results and the earlier UCI V2 Vanilla Transformer folder; the final UCI Vanilla Transformer run is `Corrected_V2_1_VanillaTransformer`. It also excludes model checkpoints, logs and raw source datasets. London final predictions and run evidence are preserved in `Results_DAT_corrected_fullbes/` and the associated cache/provenance files.
